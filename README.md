# КотоШахматы 3D (KotoChess 3D)

Локальная 3D-игра в шахматы, где все 32 фигуры — коты. Стилизованная трёхмерная арена,
полные шахматные правила, режим против компьютера (три уровня сложности) и локальный PvP.

## Запуск

```bash
npm install
npm run dev      # dev-сервер
npm run build    # production-сборка в dist/
npm test         # тесты шахматных правил и движка (56 проверок)
npm run test:e2e # E2E в headless-браузере: ход, выбор, взятие в 3D-сцене
```

Сборка в `dist/` — статическая, работает без интернета из любого локального сервера
(`python3 -m http.server`) или обёртки (Electron/Tauri) для Windows 11 x64.

## Режимы

- **Против компьютера** — основной режим. Собственный движок (alpha-beta minimax,
  quiescence, MVV-LVA, позиционные таблицы). Уровни: Лёгкий (глубина 1 + случайность),
  Средний (глубина 2), Сложный (глубина 3). Играй белыми или чёрными
  (за чёрных AI начинает партию, доска разворачивается твоей стороной).
- **На одном компьютере** — локальный PvP.

## Desktop-сборка под Windows 11 x64 (Electron)

Проект содержит готовую Electron-обёртку (`electron/main.cjs`, `electron-builder.yml`).

```bash
npm install          # при первой установке докачивается бинарник Electron
npm run build        # статическая сборка игры в dist/
npm run start:desktop  # запуск как десктопное приложение
npm run dist         # инсталлятор NSIS (release/KotoChess-3D-<версия>-x64.exe)
```

Сборка `npm run dist` скачивает Electron/NSIS-зависимости с GitHub — выполняй там,
где есть доступ к github.com (например, на Windows-машине разработчика).

## Управление

- ЛКМ по коту — выбор, подсветка доступных клеток; ЛКМ по клетке — ход.
- Перетаскивание мыши — вращение камеры; колесо — приближение/отдаление.
- **R** — сброс камеры; **Esc** — снять выделение.
- Автосохранение партии (localStorage) — кнопка «Продолжить» в меню.

## Архитектура

| Слой | Файл | Назначение |
|---|---|---|
| Chess Core | `src/game/engine.ts` + `chess.js` | Правила (chess.js, MIT) и AI-поиск |
| Game Layer | `src/game/game.ts` | Партия, очередь, результат, сохранение |
| Presentation | `src/game/scene.ts`, `src/game/cats.ts` | 3D-сцена, процедурные коты, анимации, камера |
| UI | `src/App.tsx`, `src/App.css` | Меню, HUD, диалоги |
| Звук | `src/game/audio.ts` | Процедурные WebAudio-эффекты |

Источник истины — состояние шахматного ядра; анимация не влияет на результат хода.

## Ассеты и лицензии

- Все 3D-модели котов — **процедурные, созданные кодом** (`src/game/cats.ts`), внешних ассетов нет.
- `chess.js` (npm) — MIT, шахматные правила: ходы, шах/мат/пат, рокировка, en passant, превращение, ничьи.
- `three` (npm) — MIT, рендеринг.
- Звуки — процедурные (WebAudio), файлов нет.

## Проверено тестами (`npm test`)

Ходы всех фигур, невозможные ходы, шах и невозможность оставить короля под шахом,
мат (в т.ч. мат в 1 ход, найденный движком), пат, обе рокировки и запреты, en passant,
превращение, FEN-сохранение/загрузка, легальность ходов движка.
